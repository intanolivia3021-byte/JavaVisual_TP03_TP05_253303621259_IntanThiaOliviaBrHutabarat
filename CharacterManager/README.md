# Character Manager — TP3 (Java Visual SIH-6406)
Deskripsi Project

Character Manager merupakan aplikasi berbasis Java yang dibuat untuk memenuhi tugas TP3 mata kuliah Java Visual (SIH-6406). Project ini menerapkan konsep Object-Oriented Programming (OOP), seperti class, object, constructor, encapsulation, dan enum. Project ini juga dikembangkan dengan menambahkan atribut mana, validasi nilai mana, serta method isAlive() untuk mengetahui apakah karakter masih hidup berdasarkan nilai hit points.

## Fitur Program

Program Character Manager memiliki beberapa fitur berikut:

Membuat objek karakter menggunakan constructor.

Menentukan jenis karakter menggunakan enum CharacterType.

Menggunakan atribut dengan akses private.

Mengakses dan mengubah atribut melalui getter dan setter.

Meningkatkan level karakter menggunakan method setLevel().

Menghitung statistik karakter berdasarkan level sesuai implementasi program.

Menambahkan atribut mana bertipe int.

Menolak nilai mana negatif menggunakan IllegalArgumentException.

Memeriksa kondisi karakter melalui method isAlive().

Menampilkan informasi karakter menggunakan method toString().
